To implement this project, you must first install the Ollama program, then activate the offline AI 
on your system by downloading an offline AI model onto the system and importing it into Ollama.
In this project, the 'qwen2.5-coder:7b' model was used.
This project provides you with an artificial intelligence based on the Telegram bot.
After creating your own Telegram bot, place your bot token in the token_bot.py file.
